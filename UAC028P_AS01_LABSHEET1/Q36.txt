# Question 36: Combine commands: Create a directory logs, inside it create app.log with 10 lines of dummy text using a loop or repeated echo >>, then view the last 3 lines using tail.

Answer / command:
mkdir -p logs; for i in {1..10}; do echo "Log line $i" >> logs/app.log; done; tail -n 3 logs/app.log
